## Implementation Overview

Phase 30.7 implements extraction for throw expressions which throw values for non-local returns. Throw is used to exit a computation and return a value to a catch clause, distinct from raise which is for exception handling.

### What Was Implemented

1. **Ontology Updates** (`priv/ontologies/elixir-core.ttl`)
   - Added `hasThrownValue` property to ThrowExpression class
   - Domain: ThrowExpression, Range: Expression
   - Marked as FunctionalProperty (one value per throw)

2. **Expression Builder** (`lib/elixir_ontologies/builders/expression_builder.ex`)
   - Implemented `build_throw/3` - Main throw expression builder
   - Added throw case to `build_expression_triples/3` pattern matching
   - Throw expressions linked via ThrowExpression class type
   - Thrown values linked via `hasThrownValue` property

3. **Unit Tests** (`test/elixir_ontologies/builders/expression_builder_test.exs`)
   - 5 comprehensive tests covering all throw expression scenarios
   - Test for throw with literal atom
   - Test for throw with variable
   - Test for throw with function call
   - Test for throw with tuple expression
   - Test for throw with integer literal (verifies value capture)

## Technical Details

### Throw Expression Structure

```elixir
# throw with atom literal
throw :error

# throw with variable
throw result

# throw with function call
throw compute_value()

# throw with tuple
throw {:error, reason}
```

### AST Structure

```elixir
# throw :error
{:throw, _, [:error]}

# throw value
{:throw, _, [{:value, [], nil}]}

# throw compute_value()
{:throw, _, [{:compute_value, [], []}]}
```

### IRI Structure
- Throw expression: Generated by `fresh_iri/2` from context
- Thrown value: `{throw_iri}/value`

---

## Key Implementation Notes

### Simple Implementation

Throw expressions have a straightforward AST structure - they always take the form `{:throw, meta, [value_ast]}` where the args list contains exactly one element: the value being thrown.

```elixir
def build_expression_triples({:throw, _meta, [value_ast]}, expr_iri, context) do
  build_throw(value_ast, expr_iri, context)
end
```

### Recursive Value Extraction

The thrown value can be any expression (literal, variable, function call, tuple, etc.). We recursively extract it using `build_expression_triples/3`:

```elixir
defp build_throw(value_ast, expr_iri, context) do
  type_triple = Helpers.type_triple(expr_iri, Core.ThrowExpression)
  value_iri = fresh_iri(expr_iri, "value")
  value_triples = build_expression_triples(value_ast, value_iri, context)
  has_thrown_value_triple = Helpers.object_property(expr_iri, Core.hasThrownValue(), value_iri)
  List.wrap(type_triple) ++ value_triples ++ [has_thrown_value_triple]
end
```

## Throw vs Raise

| Aspect | Throw | Raise |
|--------|-------|-------|
| **Purpose** | Non-local returns | Exception handling |
| **Caught by** | catch clauses | rescue blocks |
| **Value type** | Any term | Exception struct |
| **Use case** | Early exit from nested computation | Error conditions |
